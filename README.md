# Quantum Corsairs

A turn-based mobile duelling game in which a space pirate fights other ships using real two-qubit quantum mechanics, presented as weapon and shield tuning.

## Contents

- [`docs/concept-design-document.md`](docs/concept-design-document.md) — the concept design document: battle system, quantum model, weather, probe, factions, progression, mobile UX, technical approach and MVP milestones.
- [`prototype/index.html`](prototype/index.html) — the playable web prototype. A single self-contained HTML file; open it in a browser. It implements the battle system, coherence weather, probe scans, refits and seven factions, and shows each round as an equivalent Qiskit circuit.
